\# StravaHeatmap



Self-hosted Strava activity visualizer. Connects to your Strava account via OAuth,

imports your activities and renders them as routes and a heatmap on OpenStreetMap.



\## Status



Early development. See the roadmap in this file.



\## Tech stack



\- ASP.NET Core Web API

\- EF Core + SQLite

\- React + TypeScript

\- Leaflet + OpenStreetMap

\- Docker
